# 答案格式(分层答案模板)

最终回答必须按以下三段 markdown 结构输出,标题严格使用二级标题:

```markdown
## 结论

一到三句话,直接回答问题。面向非技术读者,不出现代码术语堆砌。

## 依据

- `src/path/file.ts:42` 一句话说明这行代码证明了什么
- `config/app.yaml:7` 配置值与含义
(每条依据 = 路径:行号 + 一句话;3-6 条为宜)

## 置信度与边界

高/中/低。一句话说明边界:未覆盖什么、什么情况下结论可能不成立。
```

规则:

- 「结论」永远在最前,读者可能只看这一段。
- 「依据」让工程师能在 30 秒内点验,这是答案可信的根基。
- 「置信度与边界」必填。证据完整闭环=高;有推断环节=中;主要靠推断=低。
- 全文控制在 500 字以内(依据列表除外),不贴大段代码。
